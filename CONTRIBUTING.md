# Contributing

Thanks for helping improve JSON Toolkit.

1. Fork the repository and create a focused feature branch.
2. Keep the app dependency-free unless a dependency is clearly justified.
3. Preserve local-only JSON processing; never add silent uploads or telemetry.
4. Keep keyboard access, labels, readable contrast and mobile layouts.
5. Test valid JSON, invalid JSON, empty input, nested values and clipboard fallback.
6. Describe changes clearly in your pull request.

Do not commit credentials, tokens, private JSON samples or personal data.
