# JSON Toolkit

A free, privacy-first JSON formatter, validator and minifier, with a practical guide to free website domains and hosting.

## Features
- Format JSON with 2 spaces, 4 spaces or tabs.
- Validate JSON and display parsing errors.
- Minify valid JSON and copy output.
- Responsive, dependency-free interface.
- Free domain and static hosting guide.
- No API keys, account or backend required. JSON is processed locally in your browser.

## Run locally
Open `index.html` in a modern browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Privacy
JSON input and output are processed locally and are not uploaded by this application. External hosting links open third-party websites only when clicked. Do not publish secrets in screenshots or issue reports.

## Free domains and hosting
See [docs/free-domains-and-hosting.md](docs/free-domains-and-hosting.md). Platform subdomains such as `github.io`, `pages.dev` and `netlify.app` are not the same as owning a custom domain. Provider terms and pricing can change; check official documentation.
