# Security Policy

## Reporting a vulnerability
Please do not publish exploitable details in a public issue. Contact the repository owner through the GitHub profile and provide a concise report with reproduction steps. Allow time for investigation before public disclosure.

## Privacy and safe use
- JSON parsing and transformation happen in the browser.
- No API key or server-side account is required.
- Do not paste passwords, access tokens or other secrets into shared screenshots or public issue reports.
- External hosting links lead to third-party services with their own policies and terms.
